支出入库

支付宝 / 微信 / 银行 / 美团 / 抖音 —— 每一笔支出自动落进备忘录。不装 App、不注册、不上传、不花钱。

它是什么

iPhone 收到支付 App 的通知 → 系统把它交给一条快捷指令 → 快捷指令把「时间 / App / 标题 / 正文」写成一行，追加进备忘录「支出流水」。

月底把备忘录复制成文本，电脑上跑一遍脚本，出月报：总共花了多少、花在哪、哪笔是退款。

第 0 步 · 三个前置检查

少做一件就抓不到金额
① 设置 → 通用 → 关于本机 → 软件版本，必须是 27.x。「收到通知时」这个触发器是 iOS 27（2026-09-14）才有的，26 及以下没有等价功能。

② 设置 → 通知 → 显示预览 选「始终」。否则正文被系统换成「1 条新消息」，金额抓不到。

③ 每个支付 App 的通知，显示位置要勾上 锁屏 或 通知中心。只勾「横幅」不触发自动化，这是系统行为。

第 2 步 · 建快捷指令（只建一次）

2
快捷指令 App → 快捷指令页 → 右上角 ＋ → 搜索并添加两个动作：
动作 1：文本 内容： [日期] | [App 名称] | [标题] | [正文] 动作 2：追加到备忘录 目标：支出流水 文本：上一步的「文本」
四个方括号就是变量。在「文本」里长按空白处 → 选「选择变量」→ 快捷指令输入 → 分别挑「日期 / App 名称 / 标题 / 正文」，中间用 | 隔开。
命名：右上角改名为 记账·通知入库。

第 4 步 · 验证

随便付一笔（买瓶水），回备忘录看是否多了一行：
2026-11-26 12:31 | 支付宝 | 支付成功 | 已支付 ¥3.00 收款方：全家便利店
有 → 成功。没有 → 回第 0 步查那三个开关，九成是通知位置没勾锁屏 / 通知中心，或者显示预览不是「始终」。

第 5 步 · 月底出月报

备忘录「支出流水」→ 全选 → 复制 → 存成 notes.txt，在你自己的电脑上跑：
python3 from_notes.py notes.txt python3 pipeline.py notes_events.jsonl --no-bills open out/report.html
退款 / 转账 / 信用卡还款自动排除，不算支出；支付宝和银行同一笔会按「10 分钟内同金额」合并，银行记录优先。

常见问题

为什么必须勾「锁屏 / 通知中心」？

通知自动化只在系统把通知投递到锁屏或通知中心时才触发，只显示横幅不触发。这是系统行为，绕不过。

微信的支付通知抓不到金额？

微信正文受「显示预览」控制，锁屏只显示「微信」两字时拿不到金额。把微信通知预览设为「始终」，或者每月用微信账单兜底。

一笔钱会不会记两次？

支付宝和银行可能各来一条，备忘录里会有两行。月报脚本会把「10 分钟内、同金额」合并成 1 笔，并优先采用银行那条。

数据会上传吗？有服务器吗？

没有。通知只写进本机备忘录，导出成文本后在你自己的电脑上算。没有账号、没有后端、没有第三方。

安卓能用吗？

不能。这套依赖 iOS 27 的通知自动化触发器。

自动化不运行 / 跑一半就停？

检查自动化里「运行前询问」是否关掉；再看设置 → 快捷指令 → 是否允许了「运行快捷指令」相关权限。第一次运行可能会弹一次网络或文件权限。
